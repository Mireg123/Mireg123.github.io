Privacy Policy

Jarvis is a personal, single-user application that runs on its owner's own computer. It is used only by its owner and is not distributed to anyone else.

Data the app accesses

With the owner's explicit permission, the app reads, creates and deletes events in the owner's own Google Calendar (OAuth scope calendar.events). It accesses no other Google data.

How the data is used

Calendar data is used only to answer the owner's requests, for example to tell the owner what is scheduled for tomorrow, or to add or delete an event the owner asked for. To produce the answer, event details may be sent to the Google Gemini API, which generates the reply shown or read aloud to the owner.

Storage and sharing

The app does not run any server and does not collect, sell or share calendar data with anyone. Sign-in credentials are stored only in the owner's Windows Credential Manager.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions and remove the stored credentials from the computer with py jarvis_calendar.py --remove.
